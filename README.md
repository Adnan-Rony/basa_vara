# বাড়িভাড়া ম্যানেজার (ধাপ ১ + ২ + ৩)

বাড়িওয়ালার জন্য offline Android অ্যাপ: বিল্ডিং → ইউনিট → ভাড়াটিয়া → মাসিক ভাড়া ট্র্যাকিং।
Expo + React Native, ডেটা ফোনেই (SQLite), কোনো সার্ভার বা লগইন নেই।

## চালানোর নিয়ম

```bash
npm install
npx expo start
```

ফোনে **Expo Go** অ্যাপ খুলে QR কোড স্ক্যান করো (ফোন আর কম্পিউটার একই Wi-Fi-তে)।

## যা কাজ করে

- বিল্ডিং যোগ/সম্পাদনা/মোছা
- ইউনিট যোগ করা, আর "একসাথে অনেক ইউনিট তৈরি" (যেমন ৫ তলা × ২ = ১এ, ১বি, ২এ...)
- ভাড়াটিয়ার তথ্য: নাম, ফোন, সদস্য সংখ্যা, ফ্যামিলি/ব্যাচেলর, উঠার তারিখ, অ্যাডভান্স
- ভাড়াটিয়া ছেড়ে দিলে আগের তথ্য "আগের ভাড়াটিয়া"-তে থাকে
- মাসিক ভাড়া: মাস বদলানো, পরিশোধিত/আংশিক/বকেয়া, আংশিক পেমেন্ট জমা হয়
- বকেয়ার জন্য SMS বা WhatsApp রিমাইন্ডার (তৈরি করা বাংলা মেসেজ)
- ড্যাশবোর্ড: ইউনিট, ভাড়া হওয়া, খালি, সদস্য, প্রত্যাশিত/আদায়/বকেয়া

## ধাপ ৩-এ যা যোগ হয়েছে

- **PDF রসিদ**: "ভাড়া" ট্যাবে পেমেন্ট সেভ করলেই "রসিদ দিন" আসে। প্রতিটি পেমেন্টের আলাদা রসিদ, টাকার অঙ্ক কথায়, WhatsApp/অন্য অ্যাপে শেয়ার। পেমেন্ট খুললে আগের রসিদও আবার পাঠানো যায়।
- **নোটিশ বোর্ড** (নিচের "নোটিশ" ট্যাব): সব বা নির্দিষ্ট বিল্ডিংয়ের জন্য নোটিশ লিখে PDF বা মেসেজ হিসেবে পাঠানো।
- **বাসার নিয়ম**: বিল্ডিং ধরে নিয়মের তালিকা, PDF (দেয়ালে লাগানোর মতো) বা মেসেজ হিসেবে শেয়ার।
- **সেটিংস** ("নোটিশ" ট্যাবের উপরে): আপনার নাম ও ফোন, যা রসিদ ও নোটিশে ছাপা হয়।

নতুন প্যাকেজ: `expo-print`, `expo-sharing`। আগের zip থেকে আপডেট করলে `npm install` আবার চালান। ডেটাবেস আপনা-আপনি আপডেট হয়, আগের ডেটা থাকবে। তবে ধাপ ৩-এর আগে নেওয়া পেমেন্টের রসিদ আসবে না (শুধু নতুন পেমেন্ট থেকে)।

## ধাপ ৪-এ এ পর্যন্ত যা আছে

- **খরচ ট্যাব** (নিচের বারে): খরচের নাম, টাকা, ধরন, নোট যোগ ও মোছা, মোট খরচ।
- **ব্যাকআপ / রিস্টোর** ("নোটিশ" ট্যাবের উপরে "সেটিংস"): সব ডেটা `.json` ফাইলে শেয়ার, আর ফাইল থেকে ফিরিয়ে আনা। ভুল বা নষ্ট ফাইল দিলে বর্তমান ডেটা অপরিবর্তিত থাকে।
- বাকি: অটো রিমাইন্ডার নোটিশ, ইউটিলিটি বিল (মিটার রিডিং)।

## জানা সীমাবদ্ধতা

- ডেটা শুধু এই ফোনে থাকে। অ্যাপ মুছলে বা ফোন বদলালে হারাবে (ব্যাকআপ ধাপ ৪-এ যোগ হবে)।
- ইউনিটের ভাড়া বদলালে যে মাসে পেমেন্ট রেকর্ড হয়নি সেই মাসগুলোর হিসাবও নতুন ভাড়ায় দেখাবে। রেকর্ড করা মাসের ভাড়া বদলায় না।
- এখনও Expo Go-তে টেস্ট করা হয়নি, প্রথমবার চালিয়ে কোনো সমস্যা পেলে এরর মেসেজ পাঠাও।

## পরের ধাপ

1. ধাপ ৪: অটো রিমাইন্ডার নোটিফিকেশন, ইউটিলিটি বিল, খরচের খাতা, ব্যাকআপ/রিস্টোর
2. ধাপ ৫: আইকন, স্প্ল্যাশ, AdMob
3. ধাপ ৬: টেস্টিং ও Play Store

## Play Store-এ দেওয়ার আগে

- `app.json`-এ `android.package` এখন `com.adnanrony.barivara`। **প্রথম আপলোডের আগে** তোমার পছন্দের নামে বদলাও, আপলোডের পর আর বদলানো যায় না।
- Release build: `npm i -g eas-cli`, `eas login`, তারপর `eas build -p android --profile production` (AAB ফাইল তৈরি হবে)।
- টেস্টের জন্য APK: `eas build -p android --profile preview`।
- একটা Privacy Policy পেজ লাগবে, কারণ অ্যাপ নাম/ফোন নম্বর সংরক্ষণ করে (শুধু ফোনে)।
